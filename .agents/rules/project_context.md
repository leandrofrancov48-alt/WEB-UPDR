# Reglas y Contexto del Proyecto: Un Poco de Ruido (UPDR)

Este archivo es leído automáticamente por el sistema de personalización de Antigravity al iniciar cualquier sesión.

## 🎯 Directrices Principales
1. **Identidad**: El proyecto es la web oficial de **Un Poco de Ruido**. Toda la comunicación, textos de juegos y estética debe respetar la cultura cumbiera y popular argentina.
2. **Juego Simulador de Carrera**:
   - Se encuentra en `/juegos/simulador-carrera`.
   - Utiliza una interfaz limpia de 2 columnas estilo Copero sin ventanas emergentes.
   - Las métricas principales son: `🌴 BAILES`, `🔥 HITS`, `🎙️ FEATS`.
   - Los templos máximos son el Movistar Arena y el Estadio River Plate.
3. **Manejo de Git**:
   - Los desarrollos en curso del simulador se trabajan en la rama `demo-simulador-cumbia`.
   - La rama `main` es para producción.
4. **Ejecución en Windows**:
   - Siempre invocar comandos de npm/npx con `cmd.exe /c "<comando>"`.
